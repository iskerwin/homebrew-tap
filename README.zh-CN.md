# homebrew-tap

[English](README.md) | 简体中文

iskerwin 的 Homebrew formula。

```sh
brew install iskerwin/tap/<formula>
```

| Formula | 说明 |
|---|---|
| [command-finder](https://github.com/iskerwin/command-finder) | 为你自己的 alias、函数和写了说明的命令提供 zsh fzf 选择器 |
| [tinge](https://github.com/iskerwin/tinge) | 用正则规则高亮终端输出，内置网络设备和服务器的规则 |
| [zsh-ui](https://github.com/iskerwin/zsh-ui) | zsh 工具共用的外观：输出辅助函数和 fzf 样式，附带朴素的 fallback |
| [zsh-remote](https://github.com/iskerwin/zsh-remote) | SSH、SFTP、Telnet 和 FTP 主机选择器，ssh-agent 管理和配置备份 |
