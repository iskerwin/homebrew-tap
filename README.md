# homebrew-tap

English | [简体中文](README.zh-CN.md)

Homebrew formulae by iskerwin.

```sh
brew install iskerwin/tap/<formula>
```

| Formula | Description |
|---|---|
| [command-finder](https://github.com/iskerwin/command-finder) | Zsh fzf picker for your own aliases, functions and documented commands |
| [tinge](https://github.com/iskerwin/tinge) | Highlight terminal output with regex rules for network devices and servers |
| [zsh-ui](https://github.com/iskerwin/zsh-ui) | Shared look for zsh tools: output helpers and fzf style, with plain fallbacks |
| [zsh-remote](https://github.com/iskerwin/zsh-remote) | SSH, SFTP, Telnet and FTP host pickers, ssh-agent manager and config backups |
